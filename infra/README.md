# infra

## Overview
Infrastructure-as-code and cloud deployment configurations for provisioning and managing PH Stocks Advisor hosting environments.

## Subdirectories & Boundaries
- [azure](./azure/README.md) - Azure Bicep infrastructure templates (`main.bicep`, `main.bicepparam`) and operational deployment/teardown shell scripts (`deploy.sh`, `teardown.sh`) for Azure Container Apps, PostgreSQL Flexible Server, and Azure Container Registry.
